# Code of Conduct

This project follows the Contributor Covenant v2.1. By participating, you agree to abide by this code of conduct.

## Our standards

We expect participants to:

- Be respectful and considerate in communications
- Use welcoming and inclusive language
- Accept constructive feedback gracefully
- Focus on the project's goals and community wellbeing

Unacceptable behaviors include:

- Harassment, abusive comments, or hateful language
- Personal attacks, trolling, or sustained disruptive behavior
- Sharing private information without consent

## Reporting and enforcement

If you encounter a violation, please report it to the project maintainer at:

`kalyankashaboina07@gmail.com`

Include as much information as possible (links, screenshots, time, and context). Reports will be handled promptly and confidentially.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, project discussions, and public or private channels maintained by this project.
